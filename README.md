### 🏗️ Data Engineering Projects

#### 🛒 [E-Commerce Analytics Lakehouse](https://github.com/Jayasurya-2/E-Commerce-Analytics-Lakehouse)
End-to-end Medallion pipeline on Databricks — 20+ notebooks across 6 source entities. Bronze layer via Auto Loader, Silver layer driven by a watermark control table with Delta MERGE, and Gold layer covering RFM segmentation, cohort retention, and executive KPIs. Fully namespaced with Unity Catalog across bronze/silver/gold schemas.

`Databricks` `PySpark` `Delta Lake` `Unity Catalog` `Auto Loader` `Delta MERGE`

#### 📡 [IoT Sensor Data Pipeline](https://github.com/Jayasurya-2/IoT-Sensor-Pipeline)
Streaming-style ingestion pipeline for 10 simulated IoT devices over 60 days of data. Auto Loader ingestion into Bronze, Silver layer built on Delta `VERSION AS OF` snapshots to solve a broken watermark pattern, and a clean Gold layer for downstream analytics.

`Databricks` `Auto Loader` `Delta Lake` `Unity Catalog`
